# Art scripts

Every texture, model and menu background in `resourcepack/` is generated by these Python scripts,
pixel by pixel (Pillow). `build_pack.py` runs them all and writes the complete pack, JSON files included.

## Rebuilding the pack

The scripts use fixed paths from the workspace they were written in:

| Path | What |
|---|---|
| `/home/claude/art/` | these scripts (e.g. `ln -s "$PWD/art" /home/claude/art`) |
| `/home/claude/ref/vanilla/` | vanilla reference files (see below) |
| `/home/claude/pack/` | the generated pack (`build_pack.py` writes here) |
| `/tmp/claude-0/` | preview images |

```bash
pip install pillow
python3 /home/claude/art/build_pack.py
rm -rf resourcepack && cp -a /home/claude/pack resourcepack
```

Single items can be rendered on their own, e.g. `python3 art/tokens.py /tmp/out` writes the Bounty Token
and the Warden's Seal into `/tmp/out`.

## Vanilla reference files

Some scripts read vanilla files (item definitions to extend, base textures for shading references).
They are Mojang's assets, so they are **not** in this repository. Take them from the Minecraft 1.21.11
client jar (`assets/minecraft/...`) and put them into `/home/claude/ref/vanilla/` with these names:

- `i_<item>.json` - item definitions from `assets/minecraft/items/<item>.json`
  (every item listed in `build_pack.py`, plus the shulker boxes and paper used by the menus)
- `m_<model>.json` - item models from `assets/minecraft/models/item/` (bow, crossbow, shield, spear, trident...)
- `<name>.png` - item textures from `assets/minecraft/textures/item/` used as references
- `steve.png`, `eq_netherite*.png`, `equip_netherite.json` - player skin and netherite armor layers
  (only for the worn-armor previews)
